# Sales Data Analysis

## Objective

The objective of this project is to analyze business performance using the Superstore Sales Dataset by examining monthly revenue trends, top-selling products, and profit distribution to generate meaningful business insights.

## Dataset

Dataset: Superstore Sales Dataset

File Used: Sample_Superstore.csv

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* VS Code
* Jupyter Notebook

## Steps Performed

### 1. Data Loading

The Superstore dataset was loaded using Pandas.

### 2. Data Inspection

Dataset structure, data types, and missing values were examined.

### 3. Monthly Revenue Analysis

Monthly sales revenue trends were analyzed to understand business growth patterns.

### 4. Top-Selling Products Analysis

Products were ranked based on total sales to identify the best-performing products.

### 5. Profit Analysis

Profit was analyzed across different categories and regions.

### 6. Business Insights

Key insights were generated from sales and profit trends.

## Visualizations Created

* Monthly Revenue Trend
* Top 10 Selling Products Chart
* Profit by Category Chart
* Profit by Region Chart
* Sales Contribution by Category Pie Chart

## Results

* Monthly revenue trends revealed business growth patterns.
* A small number of products contributed significantly to total sales.
* Technology generated strong profits.
* Regional profit performance varied across locations.
* Category-wise sales contribution provided insight into revenue sources.
